# URW base-14 fonts

The fourteen bare CFF programs the renderer draws a font with no embedded
program with (`base14-fonts`), and their licence, `OFL.txt` (SIL Open Font
License 1.1, Copyright 2016 (URW)++ Design & Development).

`25695609b209f5dd0ea92e27518714a5b20800b2`
